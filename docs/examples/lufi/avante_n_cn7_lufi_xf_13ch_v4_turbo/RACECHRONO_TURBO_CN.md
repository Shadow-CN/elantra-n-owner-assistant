# RaceChrono：伊兰特 N 涡轮压力

## 推荐配置：标准 MAP PID

Infocar 数据库中的专用涡轮压力 DID 是 `22 E0 21`，但目标两字节位于长响应较后位置。RaceChrono 的公式 `raw` 只提供 8 字节，变量也只有 A–H，因此在当前方式下无法稳定取到该 DID 的目标字节。

RaceChrono 中建议改用标准 OBD-II MAP PID `01 0B`。它返回进气歧管绝对压力，单位为 kPa，数据就在第一个字节，适合实时记录涡轮压力。

在“设置 → 车辆配置 → OBD-II 通道 → 添加通道”中填写：

| 项目 | 值 |
|---|---|
| 通道 | 优先选择“进气歧管相对压力”或“涡轮压力”；没有时选择通用“压力” |
| 通道后缀 | `TURBO` 或任意未占用编号 |
| OBD-II 标头 | `0x7E0` |
| OBD-II 反馈前缀 | 留空 |
| PID | `0x010B` |
| 测试源数据 | `0xC8` |

根据所选通道单位选择公式：

- 表压 bar：`(A - 100.0) / 100.0`
- 表压 kPa：`A - 100.0`
- 表压 psi：`(A - 100.0) * 0.1450377`
- 绝对压力 bar：`A / 100.0`
- 绝对压力 kPa：`A`

测试数据 `0xC8` 等于十进制 200 kPa 绝对压力，因此：

- 表压为 `(200-100)/100 = 1.00 bar`
- 或 `100 kPa`
- 或约 `14.50 psi`

把该通道加入“快速通道”，因为涡轮压力变化很快。温度通道可以放慢速，但涡轮压力不适合放慢速。

## 为什么不直接使用 `22 E0 21`

完整 UDS 响应以 `62 E0 21 ...` 开始。Infocar 的 `data_pos=12` 表示目标数据在完整响应的第 12、13 字节附近；而 RaceChrono 会先处理响应服务和部分 DID，公式侧的 `raw` 仍只有 8 字节。理论偏移已经超出 A–H/64 位 `raw` 的范围。

因此直接填写：

`Header=0x7E0, PID=0x22E021, bytesToUint(raw,9,2)`

在当前 RaceChrono 中很可能得到 0 或无效值。这不是车辆不响应，而是公式可见数据长度限制。标准 PID `010B` 避开了这个问题。

固定减去 100 kPa 是近似的大气压基准。若只关心 ECU 的绝对压力，请使用绝对压力公式；如果以后需要高海拔下精确的表压，需要同时读取实时大气压力并在后处理中相减。
