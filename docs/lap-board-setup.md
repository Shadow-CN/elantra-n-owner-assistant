# 圈速榜云端部署

环境：`hn-owner-asst-d7gufu33n85700993`，小程序 AppID：`wx113792b30d798c93`。

1. 微信开发者工具选择上述云环境。在 cloudfunctions/lapBoard 上右键，选择「上传并部署：云端安装依赖」。
2. 云数据库创建 `lap_records` 集合。客户端读写权限均关闭（安全规则 `{"read":false,"write":false}`），所有读取与写入经过云函数。
3. 建立两个非唯一复合索引：`status 升序, track 升序, lapMs 升序, _id 升序`；`status 升序, owner 升序, lapMs 升序, _id 升序`。若控制台自动包含 _id 尾列，则无需重复添加。以查询报错中给出的索引提示为准。
4. 云存储设置为「仅创建者可读写」，让用户可上传自己的视频；公开播放的临时链接由云函数按已发布记录生成。不要开放所有人写入。
5. 小程序后台配置隐私保护指引，声明选择媒体涉及的相册、摄像头及视频资料用途；按后台要求完成隐私接口申报。提交页已提示成绩与视频公开。
6. 真机测试：地区/赛道联动选择、八个赛道切换、有效/无效日期与圈速、两人提交后的毫秒排序、我的成绩隔离、视频选择取消、网络上传失败重试、重复点击提交、详情播放、深浅主题。

视频使用 wx.chooseMedia，选择原视频，不设置业务大小上限、不主动压缩。上传使用 wx.cloud.uploadFile，显示进度；平台和设备仍可能拒绝较大视频，不能保证任意大小。超大文件分块上传未包含在本版本。

用户自报成绩提交即公开，不设人工审核。所有提交分别展示，不按车手去重；地区按北京、浙江、上海、四川、广东、德国划分，不区分赛道布局。支持本人编辑、删除和更换视频；尚未实现自动视频内容审核或视频转码。

上传意向先写入 uploading 状态，发布重试复用 fileID 和记录 ID，不重复发布。用户离开或更换视频可能留下未发布文件/意向，应定期在云控制台检查清理；不要直接删除仍被 uploading 意向引用的近期上传。

云函数发布接口再次校验全部字段，并校验上传意向归属、环境与视频路径，客户端不能自行指定其他用户身份。公开查询不返回 owner、存储路径和 fileID。

## 媒体授权修复（2026-11-01）

## 最小隐私配置与省份推荐（2026-11-01）

在保留相册选视频、拍摄含声音的视频、公开文字成绩和自动省份推荐时，隐私保护指引声明：位置信息、选中的照片或视频信息、摄像头、麦克风、发布内容。没有读取微信昵称头像，不需要为这些功能声明微信用户信息；没有保存媒体回手机相册，不需要相册（仅写入）。

还需微信公众平台在接口权限中申请 wx.getFuzzyLocation；代码已声明 scope.userFuzzyLocation 用途和 requiredPrivateInfos。不申请精确定位或后台持续定位。后台是否允许开通以账号类目及平台审核为准。未开通、拒绝、失败或无法识别省份均保留手动选择。

进入圈速页每个应用会话自动尝试一次，先走隐私同意流程再由微信弹出位置授权。定位结果晚到时，不覆盖用户已手选或正在编辑的赛道。

省份识别在手机本地运行，使用随包携带的公开省界 GeoJSON，调用 wx.getFuzzyLocation({type:'gcj02'})。不把坐标发送到云函数或第三方地图服务，不写入成绩、日志或存储。不需要腾讯位置服务 Key，没有导航、路线规划或地图展示。

同省有赛道时默认切至同省地区第一条赛道（同省多条仍由用户选择）；无同省赛道时根据省份中心的大致地理距离推荐附近已收录地区。这是省级推荐，不能据此声称某条赛道的精确行车距离最近。境外及未匹配位置保持手动选择。

公开省界来源：https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json ，字段裁剪并将坐标保留5位小数用于本地省级计算；来源文档：https://help.aliyun.com/en/datav/datav-7-0/user-guide/map-data-format-1 。未展示地图。省界附近模糊位置可能匹配邻省，可随时手动更正。

验证：node scripts/test_location.cjs、node scripts/test_media.cjs、node scripts/test_laps.js；主包约1.55MiB，低于2MiB。
